# NumCompute demo

Open `quickstart.ipynb` in Jupyter or VS Code and run all cells from top to bottom.

The notebook expects `numcompute_student_performance.csv` in `demo/data/`, which is included in this bundle. It uses the local `numcompute` package and NumPy; no pandas or scikit-learn is required.

The benchmarking section measures the current machine's timings. Re-run the notebook and record your own Python, NumPy, platform, and timing results when preparing the assignment report.
